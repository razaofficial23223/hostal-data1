Student Hostel & University Expense Tracker
A professional and interactive expense tracking website built using Python and Streamlit.
Monthly Budget
Default monthly budget: PKR 30,000.
Features
- Hostel Rent
- University Transport
- Hostel Food
- Morning University Food
- Evening University Food
- Shopping Expenses
- Personal Expenses
- Custom Expense Categories
- Add, Edit, and Delete Expenses
- Monthly Budget Tracking
- Daily Expense Tracking
- Interactive Charts and Graphs
- Remaining Budget Calculation
- CSV Expense Report Download
Technologies
- Python
- Streamlit
- Pandas
- Plotly
- SQLite
How to Run
Install the required libraries:
pip install -r requirements.txt
Run the application:
streamlit run app.py
